Installer Precise Gunplay

  1. 1

    Télécharger

    Télécharger pour Windows

    Installeur v1.15.15, 79 Mo, avec mises à jour automatiques.

    Sans installation : version portable, sans mise à jour automatique.

  2. 2

    Passer SmartScreen

    L’app n’est pas signée. Au premier lancement, Windows affiche « Windows a protégé votre ordinateur ».

    Cliquez sur Informations complémentaires, puis sur Exécuter quand même.

  3. 3

    Autoriser une fois

    Pour la résolution étirée, Windows demande une autorisation administrateur. L’app crée deux tâches planifiées, puis ne la redemande plus.

Windows 10 ou 11, 64 bits. Gratuit et open source, sous licence MIT.
