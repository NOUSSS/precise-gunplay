Questions fréquentes

Faut-il se connecter à un compte ?

Non. Precise Gunplay lit les API locales du Riot Client lancé sur votre PC. Aucune connexion à un compte tiers n’est demandée.

L’app modifie-t-elle le jeu ?

Non. Elle ne touche jamais au processus de VALORANT. Pour la résolution étirée, elle change le pilote et la résolution de l’écran côté Windows, puis rétablit la résolution native à la fin de la partie.

Pourquoi Windows affiche-t-il un avertissement ?

L’application n’est pas signée, donc SmartScreen ne la reconnaît pas. Cliquez sur Informations complémentaires, puis sur Exécuter quand même.

Pourquoi une autorisation administrateur ?

La résolution étirée crée deux tâches planifiées. Windows vous le demande une seule fois.

Installeur ou version portable ?

L’installeur se met à jour automatiquement, c’est le choix recommandé. La version portable se lance sans installation, mais chaque mise à jour se télécharge à la main.

Fonctionne-t-elle sur Mac ou Linux ?

Non, Precise Gunplay est disponible uniquement pour Windows x64.
